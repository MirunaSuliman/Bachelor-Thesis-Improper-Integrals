# Numerical Analysis Application for Parameterized Integrals

A desktop application developed in **C#** that combines symbolic mathematics and numerical analysis to evaluate parameterized improper integrals, compute symbolic derivatives, visualize mathematical functions, and compare multiple numerical integration methods.

This project was developed as my **Bachelor's Thesis** for the Bachelor's Degree in **Mathematics and Computer Science** at **Alexandru Ioan Cuza University of Iași**.

---

## Project Overview

The application was designed to bridge theoretical mathematics and software engineering by providing an interactive environment for evaluating parameterized improper integrals.

Users can:

- Evaluate parameterized improper integrals numerically
- Compute symbolic derivatives
- Visualize mathematical functions
- Compare multiple numerical integration methods
- Estimate approximation errors
- Work with parameterized mathematical expressions

The project combines object-oriented programming, symbolic computation, numerical methods, and data visualization into a single desktop application.

---

## Features

### Symbolic Mathematics

- Mathematical expression parser
- Object-oriented expression tree
- Symbolic differentiation
- Expression simplification engine
- Parameter support
- Automatic derivative generation

### Numerical Integration

Implemented numerical approximation algorithms including:

- Rectangle Method
- Trapezoidal Rule
- Simpson's Rule
- Gauss-Legendre Quadrature

The application computes approximation errors for each algorithm, allowing users to compare their precision and performance.

---

### Function Visualization

The application provides graphical visualization of mathematical functions, including:

- Function plotting
- Integration interval highlighting
- Minimum and maximum value detection
- Interactive visualization of mathematical expressions

---

### Object-Oriented Mathematical Engine

One of the core components of the project is a custom mathematical expression engine.

Mathematical expressions are represented through an object-oriented hierarchy where each mathematical operation is implemented as an independent class.

Supported operations include:

- Addition
- Subtraction
- Multiplication
- Division
- Powers
- Trigonometric functions
- Logarithmic functions
- Variables
- Constants

This architecture enables:

- Symbolic differentiation
- Expression evaluation
- Expression simplification
- Future extensibility

## Software Architecture

The application follows a modular object-oriented architecture composed of independent components:

- Mathematical Expression Engine
- Symbolic Differentiation Module
- Expression Simplification Engine
- Numerical Integration Algorithms
- Function Visualization
- Desktop User Interface

This modular design improves maintainability and allows new mathematical operations and numerical methods to be integrated with minimal changes to the existing codebase.
